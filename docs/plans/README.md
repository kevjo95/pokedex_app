# Plans

Short-lived working documents for non-trivial changes, written before coding (`/plan`) and updated as steps complete.

- One file per piece of work: `YYYY-MM-DD-<slug>.md`, from `TEMPLATE.md`.
- A plan is for the current change. When it is done, set `Status: done`; it stays as history.
- Lasting architectural decisions do not live here: they go to `docs/adr/`.
- `HANDOFF.md` is a scratch file written by `/handoff`. Do not commit it.
