# Architecture Decision Records

One short file per significant decision, numbered, from `0000-template.md`. Accepted ADRs are immutable: change course by writing a new ADR that supersedes the old one.

Write an ADR when a decision is expensive to reverse or will surprise a future reader: new dependency, data store, pattern, service boundary, cross-cutting policy.
